OWASP Top 10 (2021)

A01
Broken Access Control

IDOR/BOLA, privilege escalation, CORS, JWT attacks

A02
Cryptographic Failures

weak algorithms, key management, SSL/TLS, padding oracles

A03
Injection

SQLi, NoSQLi, OS command, SSTI, XXE, LDAP, XPath, CRLF

A04
Insecure Design

business logic, race conditions, state machine abuse

A05
Security Misconfiguration

default accounts, headers, CORS/CSP, cloud misconfig

A06
Vulnerable Components

known CVEs, supply chain, dependency confusion

A07
Auth Failures

weak passwords, credential stuffing, JWT flaws, OAuth misconfig

A08
Software/Data Integrity

insecure deserialization, CI/CD abuse

A09
Logging Failures

missing logs, log injection

A10
SSRF

URL fetching, cloud metadata, IPv4/IPv6 bypass

OWASP Top 10:2025 changes

  • A02: Security Misconfiguration moved to #2 (from #5)
  • A03: Software Supply Chain Failures newly elevated to top-10
