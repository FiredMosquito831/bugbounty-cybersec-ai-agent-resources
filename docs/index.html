Papers that shape the design

Marked ★★★★★ in the research: architecture-defining rather than background.

01

ELFuzz: LLM-Synthesized Generation Fuzzers for Real-World Software anchor

Ohio State/NYU. CodeLlama-13B synthesizes Python-based generation fuzzers. Up to 434.8% more code coverage than second-best SOTA on cvc5 within 10 min. Fuzzer space model (lattice structure) contributes up to 62.5% to effectiveness.

02

OWASP Threat Modeling Cheat Sheet anchor

Four-question framework (Adam Shostack): What are we working on? / What can go wrong? / What are we going to do about it? / Did we do a good enough job? STRIDE categorization. anchor for agent workflow design.

open HTML ↗ source ↗
03

OWASP Top 10:2025 anchor

A03:2025 Software Supply Chain Failures newly elevated to top-10. A01:2025 Broken Access Control remains #1. Based on NVD data (~175,000 CVEs, 643 CWEs), CVSSv2/v3, incidence rates. Data covers 2021-2024.

open HTML ↗ source ↗
04

Sailor: Static Analysis-Guided LLM Harness Synthesis for Vulnerability Discovery anchor

UCSB paper. Three-phase pipeline: static analysis→LLM harness synthesis→symbolic execution→concrete validation. 379 vulns vs 12 by Claude Code alone across 10 C/C++ projects (6.8M LoC). Ablation: removing any component collapses results. anchor for agent architecture.
