Scope enforcement is not a prompt. The research is consistent: deterministic hooks outside the agent loop define what a target is, what may be touched, and when to stop.

Evidence-first. A finding without a reproducible proof-of-concept and captured evidence is a hypothesis, not a result. The agent must validate before reporting.

Next concrete steps

The archive is Phase 1. The research notes suggest this order for Phase 2:

  1. Read the anchor papers (Sailor, ARACNE, ELFuzz, NOVA, Aegis).
  2. Study the Claude Code agent repositories for orchestration patterns.
  3. Design a multi-agent pipeline with explicit scope and evidence gates.
  4. Convert disclosed-report patterns into structured evaluation data.
  5. Implement recon → analysis → validation → reporting with deterministic limits.
