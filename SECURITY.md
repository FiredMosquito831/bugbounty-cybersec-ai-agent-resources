# Security and responsible-use policy

## Reporting a problem

This is a research archive, not a service. If you find a security problem in the **site code or
build scripts** (for example an XSS vector in generated pages), report it privately through GitHub's
[security advisory](https://github.com/FiredMosquito831/bugbounty-cybersec-ai-agent-resources/security/advisories/new)
rather than opening a public issue.

## Responsible use

This archive is for **authorised security research, education and defensive engineering**.

- Nothing here grants permission to test any system.
- Obtain written authorisation from the system owner before any testing.
- Respect scope, rules of engagement and rate limits.
- Stop when a test could affect availability, third-party data or safety.

## What this repository does not contain

No exploit code, no active attack tooling, no credential dumps and no payload collections.
It contains links, metadata, papers and methodology. Referenced third-party repositories are
read-only; this project does not vouch for their safety or legality in your jurisdiction.

## Link safety

External links are catalogued from research and are not continuously audited. Treat every
dependency, script or tool linked here as untrusted until you have reviewed it.
